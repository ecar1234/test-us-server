# TESTUS SERVER
## Stack
Runtime: Node.js
Language: TypeScript
Framework: Express.js
Architecture: Clean Architecture
Presentation Pattern: MVVM
Authentication: JWT
File Upload: Multer
Scheduler: Cron
Realtime Communication: Socket.IO
ORM: TypeORM
Database: MySQL (mysql2 driver)
Cache / PubSub: Redis
Reverse Proxy: Nginx
Secure Access: Cloudflared Tunnel
Process Manager: PM2
  
This server is for the TESTUS app.
